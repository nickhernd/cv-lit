\section{Archivos disponibles}

\begin{description}
  \item[\texttt{obscape\_api.py}] Cliente Python para descarga automática
        de imágenes y metadatos via API Obscape. Funcional pero sin acceso
        a las cámaras de Guardamar todavía.

  \item[\texttt{proces\_images/images/}] Dataset de prueba PTM61474:
        $\approx 90$ imágenes horarias (04:00h--18:00h) del 29/04/2026
        al 06/05/2026.

  \item[\texttt{proces\_images/horizon\_correct.py}] Script de corrección
        interactiva de curvatura de horizonte.

  \item[\texttt{map\_ubication.png}] Mapa de la ubicación del proyecto
        ``Ketel Haven'' en Obscape (Países Bajos).
\end{description}
