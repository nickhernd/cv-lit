Guardamar del Segura. Son propiedad del \textbf{Ayuntamiento de Guardamar del

\begin{itemize}
  \item Todas las estaciones son de tipo \emph{Camera} con 1 dispositivo acoplado.
  \item CAM 3 (8212, PTM61473) y CAM 4 (8211, PTM61475) están muy próximas

  \item CAM 5 (8209, PTM61472) y CAM 6 (8210, PTM61470) también son casi
        coincidentes en posición (38.0767--38.0768°N, $-0.6481°$E).

        el 2026-05-20 entre 15:01 y 15:03 UTC+2.
\end{itemize}

\section{Dataset de prueba disponible}

El dataset manual corresponde a la \textbf{CAM 2} (Station ID 8214,
referencia PTM61474). Contiene $\approx 90$ imágenes horarias
(04:00h--18:00h) del 29/04/2026 al 06/05/2026, almacenadas en
\texttt{proces\_images/images/}.

\section{Acceso via API}

Con los Station IDs reales ya es posible consultar cada cámara:

\begin{Verbatim}
# Listar datos de CAM 1 (últimas 24h)
python obscape_api.py --project <nombre> --station PTM61471 --latest 24

# Descargar imágenes de CAM 2 en rango de fechas (solo 12:00h)
python obscape_api.py --project <nombre> --station PTM61474 \
    --from 2026-05-01 --to 2026-05-20 --download
\end{Verbatim}

\textbf{Pendiente:} confirmar el nombre del proyecto Obscape bajo el que
están registradas estas estaciones (ver Capítulo~\ref{chap:api}).
