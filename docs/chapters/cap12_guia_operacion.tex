\section{Calibración}

\begin{warnbox}[Ya no hay herramienta de calibración por línea de comandos]
Las herramientas CLI que existían anteriormente (\texttt{calibration\_tool.py},
\texttt{visualizar\_calibracion.py}, \texttt{recalibrate.py}) se eliminaron durante el
endurecimiento del proyecto para producción: quedaban duplicadas con el asistente web y sin
mantenimiento. La calibración se hace exclusivamente desde la interfaz web, pestaña
\textit{Calibración} — asistente de 7 pasos (Vista general → Imágenes → Alineación → Catálogo
→ Marcación → Cálculo → Validación), detallado en el capítulo~\ref{ch:calibration}. Verificar el
motor matemático de la homografía se hace ahora con
\texttt{python -m pytest tests/test\_homography\_math.py tests/test\_geometry\_warning.py}.
\end{warnbox}

\section{Alineación masiva (CLI)}

Para usar el módulo de alineación sin interfaz web:

\begin{codebox}[]
\begin{minted}{bash}
# Alinear todas las imágenes de una carpeta respecto a la primera
python3 homography/align_images.py \
  --input  /ruta/imagenes/ \
  --output /ruta/salida/ \
  --cam 1                    # aplica máscaras SIFT de CAM_1

# Especificar imagen de referencia manualmente
python3 homography/align_images.py \
  --input  /ruta/imagenes/ \
  --output /ruta/salida/ \
  --ref    imagen_base.jpg \
  --cam 2
\end{minted}
\end{codebox}

Salidas:
\begin{itemize}[leftmargin=1.5em]
  \item \texttt{/output/aligned/} — imágenes alineadas
  \item \texttt{/output/diagnostics/} — visualizaciones de matches
  \item \texttt{/output/homographies.csv} — métricas y matrices $H$ por imagen
\end{itemize}

\section{Operación del día a día: Auto Mode}

Para el uso operativo normal (procesar imágenes nuevas de una cámara ya calibrada) no hace
falta ninguno de los pasos anteriores: pestaña \textit{Modo automático} de la interfaz web,
elegir cámara + rango de fechas y pulsar \textit{Iniciar procesamiento automático}. El sistema
descarga, alinea y analiza todo el lote sin intervención manual (capítulo~\ref{ch:automode}
explica el pipeline interno). Requisito: la cámara debe tener ya al menos una calibración
calculada — si no, el botón queda deshabilitado con el aviso correspondiente.

\begin{itemize}[leftmargin=1.5em]
  \item El panel \textit{Estado por cámara} de esa misma pestaña resume de un vistazo qué
        cámaras están calibradas y con qué RMSE.
  \item El panel \textit{Actividad de Auto Mode} muestra en tiempo real el log filtrado a solo
        los mensajes de este módulo (\texttt{GET /api/logs}, prefijo \texttt{"Auto Mode"}).
  \item Marcar \textit{Exportar GeoJSON automáticamente al terminar} descarga el GeoJSON de la
        cámara en cuanto el job pasa a \texttt{done}, sin tener que volver a la pantalla.
\end{itemize}

\section{Aplicación de escritorio (sin entorno de desarrollo)}

Para un operador que no necesita tocar código, el instalador de Windows
(\texttt{installer/output/LineaDeCosta-Setup.exe}, capítulo~\ref{ch:setup}) monta la misma
interfaz dentro de una ventana nativa (pywebview) sin necesitar terminal, Python instalado ni
levantar servidores a mano — el ejecutable arranca el backend en segundo plano y abre la
ventana automáticamente.
